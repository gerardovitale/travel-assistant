Acerca del proyecto

Datos de combustible claros, para decidir mejor cada repostaje.

Fuel Precision es un proyecto de codigo abierto que consume a diario los precios oficiales de las estaciones de servicio de España y los convierte en información útil: dónde repostar más barato, cerca de ti o en tu próximo viaje.

Motivación

El precio del combustible cambia cada día y entre estaciones cercanas puede variar de forma notable. Esa diferencia, repetida a lo largo del año, es dinero real. Fuel Precision nace para hacer esa diferencia visible y sencilla de aprovechar.

Detrás hay una plataforma de datos completa: pipelines que ingestan diariamente los precios oficiales del Ministerio, los limpian y agregan en métricas, y los sirven a través de una API pública y de este sitio web. Todo el código es abierto y verificable.

Soy Gerardo Vitale, Data Engineer, y construyo y mantengo este proyecto. Para mí es a la vez una herramienta práctica para conductores y una muestra abierta de cómo llevar un sistema de datos desde la ingesta hasta el producto final.

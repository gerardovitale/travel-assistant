# Claude Design sync notes

Target project: "Fuel Precision Design System" — https://claude.ai/design/p/509476d5-cdbf-4fd6-9801-44b588b31a22

## How this project is maintained (read before any /design-sync run)

- The project is **hand-authored**: React components (`components/**`), a `ui_kits/fuelprecision/`
  site recreation, guideline cards, assets and design handoffs, all reading
  `window.FuelPrecisionDesignSystem_509476` from its own `_ds_bundle.js`.
- The repo has **no component library** (Jinja2 + Tailwind CDN), so the standard converter can
  only produce a tokens-only build with an EMPTY `_ds_bundle.js`. **Never run the converter
  upload against this project** — it would overwrite `_ds_bundle.js`/`styles.css` and break every
  component and the ui_kit. (Decided 2026-10-22 with the user.)
- Repo-derived content is limited to a few files, updated by hand-scoped uploads:
  - `tokens/tailwind.css` — generated by `node .design-sync/pkg/build.mjs` (see `buildCmd`) from
    `fuel-dashboard/app/web/templates/base.html` (tailwind.config) + templates + static JS.
    Tailwind 3.4 (CDN major), preflight OFF, `@tailwindcss/forms` with `strategy: 'class'` so it
    is purely additive and existing components render unchanged.
  - `styles.css` imports it last.
  - Motion/shadow tokens in `tokens/spacing.css`, stagger classes in `tokens/base.css` and the
    "Designing changes to the live site" section of `readme.md` mirror the app by hand.
- Upload recipe: stage changed files in `.design-sync/.cache/upload/`, `finalize_plan` with exact
  paths (no deletes), write `_ds_needs_recompile` first and last. No `_ds_sync.json` anchor is
  written (the bundle is not converter-built, so an anchor would be dishonest).
- Pre-change remote copies of the 4 overwritten files: `.design-sync/.cache/remote-backup/`
  (gitignored, local only).

## Re-sync risks

- `tokens/spacing.css` motion/shadow values and `readme.md` guidance are hand-mirrored from
  `static/css/tokens.css` and Tailwind defaults — they drift if the app's tokens change.
- The ui_kit screens (Search/Trip/Insights/About) were recreated before the round-trip and
  route-options trip features landed; they may lag the deployed UI.
- `tokens/tailwind.css` only contains classes found in templates/JS plus the safelist in
  `build.mjs`; classes outside both are not compiled.
